## Input compatibility

Chrome uses `importExternalTexture` with texel-centred external sampling and explicit transfer to linear premultiplied color. The current WebKit external path failed the unchanged Canvas2D reference even on uniform interior patches: one linear red sample was approximately 0.1219 instead of 0.0003035. A VideoFrame snapshot produced the same discrepancy. WebKit therefore uses an owned Canvas2D snapshot uploaded through `copyExternalImageToTexture`; SwiftShader uses a CPU writeTexture fallback because its external-image interoperability fails. The selected path is exposed as `inputMediaPath` and recorded in the video gate. Pixel tolerances were retained.

A decoded frame invalidates video input; unchanged frames reuse the owned mip chain. Caller media and browser permission prompts stay outside the core runtime. The playground owns the media it creates and closes contexts, stops tracks, cancels callbacks, revokes URLs and destroys secondary fields on replacement or unmount. Async builds and updates reject stale device generations. Borrowed textures remain caller-owned.

Shared-device recovery restores fields sequentially. A surface can resize or present only with a resolve pipeline from the current device generation, including the interval when the replacement device is ready but that surface has not yet restored. This prevents observer callbacks from combining an old pipeline layout with new textures. Restoration checks disposal between awaited stages; stale LUT jobs cannot overwrite a disposed field or a newer successful parameter update. Every borrowed binding has its own invalidation subscription, so replacing or clearing one binding preserves the others.

## Numerical and presentation limits

JFA is approximate; radiance cascades use ordinary bilinear merging and bounded diffuse iterations, with documented visibility leakage and angular aliasing. Half-float convolution tests separate per-pixel agreement from a derived two-storage relative error bound. Kuwahara guards the undefined flat-gradient atan2 case. A filter returns premultiplied linear color; PNG export converts SDR readback to straight-alpha ImageData before encoding.

Compare starts both previews from the selected seed when it is enabled or the right effect changes. This gives stateful effects a common initial state rather than pretending that matching frame indices copy simulation history. Media state is shared independently of the simulation clock. Recording codecs are feature-detected, and unsupported engines report that recording is unavailable. PNG and video capture use straight-alpha SDR GPU readbacks. Video paints an owned Canvas2D compositor before starting MediaRecorder and after each completed readback, avoiding blank native WebGPU canvas streams. GPU-to-CPU copying and 2D upload add capture cost; recording cadence depends on readback completion. This export path is excluded from GPU benchmarks. Pending starts and paints are generation-guarded, and a replaced Compare field discards its stale capture pair.

## Combined validation and measurements

Correctness validation completed on 2026-10-07:

- `pnpm test`: 41 unit tests and the catalogue/export authoring check pass.
- Workspace and browser-test types, package declaration builds and formatting pass.
- `pnpm exec playwright test`: all 312 software tests pass at DPR 1 and 2. After the device-generation guard, the 20 canvas, pixel and lifecycle cases pass again at both DPRs.
- `pnpm exec playwright test --config playwright.hardware.config.ts --project chrome-hardware --project webkit-hardware`: all 310 tests pass. Firefox was not launched for this milestone.
- The 390-pair matrix connects all 39 effects to all ten core T4 filters, including the two lighting filters, with correct input/output dimensions, no GPU validation errors and baseline surface cleanup. It passes on both software resolutions, Chrome and WebKit.
- All eleven new effects have deterministic default and two-preset snapshots at DPR 1 and 2, alongside numerical tests and within-engine hardware replay. Input and filter references, live media, borrowed-source lifetime, cycle guards, independent shader edits, actual recording content and transparent Compare composition are covered separately.
- Final production QA passes in Chrome and WebKit: all eleven measured notes and 22 benchmark links per engine load; actual 1080p video and all seventeen 3D LUT planes are available; independent Compare parameters, PNG dimensions and teardown are verified. Eight production capture/Compare cases pass, including actual recorded video decoding and transparent split composition. Source-module capture cancellation regressions run in the development suites above.
- The effects sidebar has a capped scrolling list; its final effect remains reachable on desktop and mobile. At 390×844, the list is 295 px tall, uses two columns and introduces no horizontal page overflow.
- The recovery test forces a resize while a new shared device is ready and a peer's restore is deferred. It proves that the old resolve pipeline is skipped, a field can be destroyed during restoration, and the surviving field recovers its actual LUT pixels without validation errors. Delayed failed LUT jobs cannot change disposed or newer successful state.

Production measurements contain 72 rows: three default runs for each of the eleven new effects in each engine (66), plus three video-chain runs per engine (6). Individual research notes contain parameter tables and measured CPU, completion, GPU-pass and cadence values linked to [Chrome defaults](benchmarks/m4-chrome.json) and [WebKit defaults](benchmarks/m4-webkit.json).

The refresh gate uses an actual decoded 1920×1080 60fps clip through default Gaussian radius-8 blur, lens, color-grade and dither. Input, intermediate and output taps remain full HD, fixed quality and seed 7. Each run completes 150 fixed updates, discards 30 warm-up frames and measures 120 workloads; all filter pass timestamp labels have 120 samples. Decoder progression and distinct input hashes verify changing video rather than a static frame. The criterion requires at least 95% of completions and median frame cadence within 110% of the separately measured idle rAF period.
