# ADR 014: owned shadow decorations and external uniform clocks

Status: accepted for M5.

`attach(host, effect, options)` owns a decorative shadow-root canvas and a slot. The authored children stay in the light DOM: buttons, links, headings and selection remain accessible. The canvas has `aria-hidden="true"` and `pointer-events:none` in both layers. Pointer uniforms listen on the host without capturing pointer events from interactive children. The backing size follows the canvas while visibility follows the host. The shadow wrapper establishes a block formatting context so the first slotted heading cannot collapse its top margin through the wrapper and shift the decorative canvas.

The attachment enables adaptive quality by default; fixed-quality measurements explicitly opt out. It returns one parameter proxy, including without WebGPU. No GPU, no adapter and missing required features show an author poster first, then the effect CSS fallback. A fallback still supports parameter updates and presets. Device loss belongs to the shared core session: attachments deduplicate lost events, keep the last presentation or poster, then emit restored after their resources are rebuilt. Pipeline and author parameter errors remain errors rather than being silently mislabeled as unavailable GPU support.

Initial custom-element ready and fallback listeners see the live attachment and stable parameter handle. Initialization follows a replacement device even if loss occurs before the field registers its regular state listener. GPU operations reject or skip stale generations, and teardown submits pending encoded commands before destroying their resources.

Pixel capture selects the current rendered target after its asynchronous pipeline creation. A resize during compilation paints the new target before capture; a resize after the copy was submitted preserves that owned snapshot. Device replacement and disposal still reject capture, and every path releases the readback pass and staging allocations.

An attachment owns its style, wrapper, canvas, poster and subscriptions. Destroy removes those nodes and restores its previous state attribute; a plain shadow slot remains because the platform cannot detach a shadow root. Existing author shadow roots are rejected. Authored content and inline styles are never rewritten. Abort signals dispose decoration immediately while a pending GPU creation eventually releases its field. Custom-element import and creation epochs prevent disconnected or superseded imports from reviving nodes. The element can reconnect and reads the latest attributes. Registration is an explicit side-effect entry; the ordinary DOM module is safe to import on a server.

CSS bridges run in `onBeforeFrame` once before simulation and uniform upload. `setFramePolling` keeps a driver awake without advancing a paused simulation; unchanged uniforms preserve the existing settled GPU image without submitting a frame. Changed uniforms paint in the same frame, and offscreen hosts and hidden tabs still sleep. Direct parameter properties remain the cheapest bridge. `timeline(progress)` accepts a finite 0–1 clock, pauses the rAF simulation clock, writes normalized procedural time with zero delta and invalidates one frame. An unchanged clock leaves the settled image untouched; validation still rejects nonfinite clocks. It does not replay stateful simulations backwards. Reduced motion keeps the declared settled time and reduced pointer velocity.

Property and timeline drivers own their polling subscription and expose call, applied-change and error counters. Exceptions from an author source emit bounded, deduplicated `hgpu-error` events without stopping other scheduled fields; later valid source values recover. Disposing the last driver restores the original polling state.

DOM rectangle sources refresh before visible frames and own mutation/resize observers. Spotlight uniforms share viewport CSS pointer coordinates and use each host's viewport CSS bounds. Border energy takes the actual host radius and full normalized local rect. Text inputs derive a raster mask from authored text while the original text remains accessible.

The browser suite exercises all three fallback causes, poster priority, stable handles, child hit testing, timeline validation, actual `device.destroy()` recovery, lazy disconnect/reconnect, abort during pipeline creation, actual paused-host resize, offscreen sleep and reduced pointer motion on software Chromium and native Chrome/WebKit. CSS bridge correctness and style-read cost are tested and measured separately.

The shared scheduler admits one scheduled GPU batch at a time, resuming on rAF after genuine queue completion. All active fields retain dependency order and fairness; slow work cannot create an ever-growing queue of old frames. A long queue wait caps the first resumed simulation update to one step. Device loss clears the obsolete admission lease, while identity tokens prevent old queue callbacks from unblocking a newer batch or replacing a new quality sample. Manual `advance`, capture and readback remain explicit caller-driven operations.

Normal quality warmup and recovery hysteresis remain. A genuine completion sample over eight frame budgets takes the emergency path: measured overload reduces pixel scale and step work immediately within each effect's declared bounds. This rule uses completed work rather than adapter names or artificial pressure. A pending completion cannot prevent a replacement device from taking new samples. The admission-hold browser test verifies queue bounds and fair resumption; the actual software-adapter benchmark separately establishes adaptation and performance.
