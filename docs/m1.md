# M1 validation record

M1 implements the shared runtime and frozen T1 helper, the six Family A Core effects, the Full-stage playground shell, and research notes. The [T1 contract ADR](adr/005-t1-effect-contract.md) documents colour, coordinates, parameter packing and lifecycle ownership; the [public facade ADR](adr/006-public-package-facade.md) records package boundaries.

## Deliverables

- Device session, canvas surface, fixed-step scheduler, keyed resource leases, transient texture pool, validated parameter store and generated WGSL layout.
- Chunk composition with source locations; seeded hash, five noise modes, colour transforms, SDF functions, fullscreen pass and SDR resolve.
- `fragmentEffect` and individual exports for `gradient-oklch`, `noise-lab`, `voronoi`, `sdf-2d`, `raymarch`, `fractal`.
- Catalogue discovery, search/family filter, Full stage, schema-generated inspector and presets, URL state, read-only composed Source, Capabilities, Notes and CPU encode timing. Basic transport, seed, resolution and reduced-motion controls are also included.
- [Research note template](notes/_template.md) and six completed notes with generated parameter tables and linked measurements.
- [19-line effect](../examples/bands.ts) plus a temporary-workspace discovery test for the under-50-line exit criterion.

## Verification

The completion pass is recorded below. Thirty-six deterministic software snapshots cover defaults and both presets for all six effects at DPR 1 and 2. Tests compile both presets and every enum path, read pixels twice with fixed time/seed, check disposal, share a device between fields, exercise generated controls and URL reload, verify premultiplied alpha, and probe the paired-f32 residual and compare bounded arithmetic against a CPU reference. Software rendering does not establish hardware speed.

The fixed hardware benchmark uses 512×320 targets, DPR 1, defaults, seed 7, a 1/60 s clock, 30 warm-up frames and 120 measured frames for each of three runs. It reports CPU encode/submit time and rAF cadence. GPU timestamp timing is deferred to M3. Measurement runs use a production preview to avoid development reloads. Logical memory is 1.25 MiB per float target plus two small uniform buffers; this is not VRAM.

## Scope and limits

The M1 shell does not implement the later gallery, Compare/Grid/In-page stages, inputs, live editor, timestamp profiler, recordings or DOM custom element. Texture-backed curve/gradient/texture schema types belong to the M4 input/binding layer; the frozen T1 types are documented explicitly. The retained M0 lab has its own static entry and regression tests. Firefox's headed hardware pass and native Safari/Firefox coverage over the full catalogue remain in M8; M0 compatibility evidence remains available.

The fractal's double-single option uses integer reconstruction barriers to preserve intermediate f32 rounding. Hardware checks caught and corrected a Metal reassociation failure; bounded add/multiply tests now agree with a CPU f64 reference. This does not establish native f64 precision or full fractal iteration error bounds. High-frequency noise and cellular edges can alias, and the ray marcher uses bounded heuristic shadows/AO. Each note records these limits and what production work remains.
