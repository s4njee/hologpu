# M7 — Selected stretch effects

Implemented 2026-10-07. M7 takes the six suggested first picks in the plan, in addition to all 47 core effects and the three procedural stretches implemented earlier. [ADR-019](adr/019-selected-stretch-research.md) defines scope and approximation boundaries.

## Implementation and research questions

| Effect              | Concrete probe                                                                                      | Default workload                                                  | Boundaries                                                                                                                                                    |
| ------------------- | --------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `mpm`               | Quadratic B-spline P2G, APIC affine momentum, grid forces and G2P deformation without float atomics | 1024 particles, 32² nodes, four transfer substeps                 | Gather P2G is O(nodes × particles). Liquid is weakly compressible; jelly is compressible neo-Hookean; snow is volumetric plasticity, not SVD snow.            |
| `pbf-fluid`         | Sorted exact neighbors, SPH density lambdas, Jacobi correction and reconstructed velocities         | 256 particles, three constraint iterations                        | Neighbor ranges are rebuilt each iteration. Compression-only constraints, bounded corrections and simple walls; no tensile pressure or vorticity confinement. |
| `lattice-boltzmann` | D2Q9 pull streaming, BGK collision, solid-link bounce-back and periodic conservation                | 96² cells, nine f32 populations, four lattice ticks               | The driven channel has an equilibrium inlet and copied outlet. Its mass is not the closed periodic reference; the boundary is not Zou–He.                     |
| `path-tracer`       | Progressive compute radiance through a packed median BVH                                            | Seven analytic spheres; one path/pixel/update, four bounces       | Lambertian/mirror scattering and emissive/sky light; no MIS, denoising, asset loading or hardware ray-tracing API.                                            |
| `splats`            | Perspective covariance projection, inverse Gaussian conics and GPU transparency sorting             | 2048 procedural 3D Gaussians                                      | Center-depth radix sort; source-order comparison. No trained asset loader, SH radiance, tiled binning or optimization.                                        |
| `backdrop-glass`    | Real DOM paint captured into a lens/refraction filter                                               | Owned texture preview by default; explicit opt-in capture fixture | Requires HTML-in-canvas. Captures a direct child of an existing drawable source canvas, rather than arbitrary content behind a DOM element.                   |

All six definitions expose generated controls, two presets, individual exports, composed sources, intermediate taps, quality ranges, deterministic reduced-motion poses and CSS fallbacks. MPM and PBF render additive thickness into a screen-space normal/lighting surface. Splats add a premultiplied alpha-over option to the particle draw helper; existing rendering defaults remain compatible.

The existing sort, prefix sum and spatial hash cover this selection. No new Family I primitive is required by these dependants.

## DOM capture experiment

`createElementCapture(session, element, onChange?)` and `elementCaptureMethod(queue)` are public core helpers. The caller owns the source DOM/canvas. The adapter owns its sRGB texture and paint listener, reallocates on source size changes, preserves the source on disposal, and can capture an existing painted snapshot during device reconstruction. Straight-alpha sRGB samples are decoded and premultiplied before interpolation in the glass filter. Raw tap readback retains encoded channels.

The playground provides an explicit **Enable DOM capture** button and an editable real DOM source fixture. Unflagged Chrome, Firefox and WebKit show a labeled texture preview and a disabled capture button. No origin-trial token or browser flag is silently enabled for normal use.

Local Chrome 154 exposes both queue spellings under `--enable-blink-features=CanvasDrawElement`, but its draw-named alias still expects the older `destination/width/height` dictionary. The adapter pairs the method with the canvas API generation: legacy `layoutsubtree` uses the proven copy method; newer `content="drawable"` selects the documented draw method. The Chrome 155+ dialect needs a browser that implements it before it can be marked validated. See [Chrome's API migration documentation](https://developer.chrome.com/blog/html-in-canvas-ot-changes).

## Validation

Type checking, 74 unit tests, catalogue generation, formatting and the production build pass. All 36 M7 software cases at DPR 1/2 and 55 applicable hardware cases pass: 19 in Chrome, including flagged DOM capture, and 18 each in Firefox and WebKit. The optional capture test is intentionally skipped in the other engines and software projects. All 74 applicable cases in the combined software regression have passing final results, including the existing particle helpers, M6 catalogue and the Cartesian matrix of every current effect feeding each core T4 filter.

```sh
pnpm typecheck
pnpm test
pnpm exec playwright test tests/browser/m7-catalogue.spec.ts tests/browser/m7-correctness.spec.ts tests/browser/m7-lifecycle.spec.ts
pnpm exec playwright test tests/browser/m7-catalogue.spec.ts tests/browser/m7-correctness.spec.ts tests/browser/m7-lifecycle.spec.ts tests/browser/m7-capture.spec.ts --config playwright.hardware.config.ts
pnpm format:check
pnpm build
```

Numerical references cover transfer partition/momentum conservation; PBF density, neighbors, lambdas and one correction against all-pairs CPU equations; complete periodic D2Q9 stream/collision against CPU and multi-tick mass conservation; BVH primary hits against brute-force spheres; progressive path counts and camera/exposure invalidation; Gaussian order/permutation and positive conics; and a zero-distortion borrowed-image identity.

The PBF reference caught a host/shader dimension mismatch: double-precision host division floored 1/f32(0.1) to 9 while WGSL f32 division rounded it to 10. The host now reproduces that f32 division before flooring. Shader tests also caught non-uniform allocation controls referenced as WGSL parameters; shaders now derive their allocation counts from bound arrays.

Stateful recovery tests explicitly reset the initial seed before comparing reconstructed initial pixels. Changing only the display clock does not reseed a feedback simulation. Development HMR is disabled in the tests so catalogue generation cannot replace a field during capture. Transparent-effect screenshots use an explicit fallback backdrop, and the filter matrix explicitly fixes resolution scale and uses small solver allocations; hardware measurements independently cover the full defaults.

Four early Chrome cases could not load the app while the development server cached unresolved imports during concurrent catalogue edits. Restarting cleared the cache; the complete 19-case Chrome rerun passed. Firefox and WebKit each passed all 18 applicable cases. This records a development-server interruption rather than a shader/browser capability failure.

## Measurements

[Chrome rows](benchmarks/m7-chrome.json) and [WebKit rows](benchmarks/m7-webkit.json) record the selected default workloads. Apple M1 Max / macOS 26.6.2, production preview, physical 512² display, DPR 1, seed 7 and fixed resolution/work quality. Three runs/effect/engine; 30 warm-up updates plus 120 measured fixed 1/60 s updates, one per rAF, with queue completion and timestamp readback awaited. Each run verifies typed defaults, actual storage sizes, complete timestamps where available and no GPU errors.

Ranges across the three runs (milliseconds):

| Effect                   | Chrome CPU mean | Chrome completion p95 | WebKit CPU mean | WebKit completion p95 |
| ------------------------ | --------------- | --------------------- | --------------- | --------------------- |
| MPM                      | 0.199–0.242     | 5.7–6.0               | 0.183–0.325     | 11–12                 |
| PBF fluid                | 0.495–0.544     | 9.2–9.7               | 0.392–0.567     | 13–14                 |
| Lattice Boltzmann        | 0.195–0.218     | 1.8–1.9               | 0.275–0.358     | 4–5                   |
| Path tracer              | 0.184–0.208     | 2.4–2.5               | 0.258–0.325     | 5–6                   |
| Splats                   | 0.280–0.291     | 3.5–4.8               | 0.300–0.467     | 7–10                  |
| Backdrop texture preview | 0.176–0.207     | 2.1–2.8               | 0.217–0.342     | 4–6                   |

All 36 rows report the actual Apple Metal adapter rather than a fallback. Median observed cadence was 16.7 ms in Chrome and 17 ms in WebKit. All untimed numerical reproductions retained finite state.

A separate untimed reproduction after each run executes 150 fixed updates at the same physical size and reads all selected f32 state taps to verify finiteness. The Profiler runner restores/reset state in its `finally` block, so inspecting those freshly reset buffers would not verify the measured evolution. Numerical reproduction and readback are outside all reported timings.

CPU encoding/submission, encoding-through-queue-completion latency, summed per-pass timestamp diagnostics and rAF cadence have different boundaries. Quantization and overlapping timestamp intervals limit interpretation. Initialization/compilation are excluded, machine load is uncontrolled, and logical allocation sizes are not driver VRAM. Backdrop rows measure the texture preview and exclude HTML-in-canvas capture, layout and source painting. No M7 refresh-rate exit gate is claimed.

## Remaining stretches and hardening

Twenty-three catalogue stretches remain deferred: four feedback effects; shallow water/multigrid; cloth/ribbons; five filter stretches; stippling; marching cubes/volumetrics/voxels/culling; transition wipe/chart post; and histogram/FFT/generated blue noise. They are not marked implemented. Future selections should answer a new question and include their needed primitive rather than filling catalogue slots for completeness.

M8 retains cross-device measurements, optional-feature/compatibility/worker experiments, budget enforcement, extended stability, native-browser/manual touch/HDR checks and the findings write-up. This milestone's bounded solver and capture tests do not replace those checks.
