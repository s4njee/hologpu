# @mk7s/hologpu-core

The core WebGPU runtime behind HoloGPU: one shared device and scheduler, the
effect contracts (`defineEffect`, `fragmentEffect`, `feedbackEffect`,
`particleEffect`, `chain`), the parameter store, resource and target helpers, and
the shared WGSL chunks.

Part of [HoloGPU](https://github.com/s4njee/hologpu). Most users want the facade
[`@mk7s/hologpu`](https://www.npmjs.com/package/@mk7s/hologpu) instead.

```sh
npm install @mk7s/hologpu-core
```
